# ntforum-visited-fix
Fix the ntforum visited links issue in Chrome

1. Open Chrome Extensions Page

   • Go to chrome://extensions/ in your address bar

   • Or: Menu (⋯) → More tools → Extensions

3. Enable Developer Mode

   • Toggle the "Developer mode" switch in the top-right corner (it will turn blue)

5. Click "Load unpacked"

   • A new button will appear at the top-left

   • Click it

6. Select Your Folder

   • A file browser will open

   • Navigate to your unpacked extension folder

   • Select the folder that contains the manifest.json file

   • Click "Select Folder"

8. Done!

   • Your extension will now appear in the extensions list

   • It should be enabled by default

Important: The folder you select must contain a manifest.json file at the root level.

Tips:

• If you make changes to your extension code, click the refresh icon (⟲) next to your extension to reload it

• You can pin the extension to your toolbar by clicking the puzzle icon and selecting the pin icon

• If there are errors, click your extension card to see the error messages in the "Errors" section
